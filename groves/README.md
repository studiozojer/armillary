# groves — places, not protagonists

A grove is a domain corpus that holds rather than acts — a place with a self and a schema, but no agenda. Readings, people, observations, journal entries: the lived substrate of a domain.

Unlike an **operator** (a composed identity that routes sessions and takes action), a grove is a site. It receives. It holds. It makes its contents traversable. Tycho casts and reads; Dodona holds what's been read.

Each grove is its own independent git repo, dropped into this folder as `groves/<grove>/`. Everything in here is **gitignored** except this README — the router never tracks what its places hold.

Declare what groves you compose in `modules.toml` (using `[[operators]]` with a `path` under `groves/`, until the schema graduates its own section).
